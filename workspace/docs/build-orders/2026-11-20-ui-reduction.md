# UI-REDUKTION — LYKOS REIMARCHIV

Das aktuelle Frontend ist unnötig aufgebläht. Es enthält zu viele Statusanzeigen, Platzhalter, Übersichtskarten und dekorative Elemente ohne konkrete Funktion.

## Auftrag

Reduziere das Frontend auf eine minimalistische, funktionale Arbeitsoberfläche.

### Entfernen
- Dashboard mit Übersichtskarten
- Schnellzugriffe
- Entwicklungsstatus-Übersichten
- Roadmap-Karten
- Redundante Statusanzeigen
- Nicht benötigte Informationsfelder
- Platzhalter ohne konkreten Funktionsbezug

### Navigation
- Reimarchiv
- Reimzeilen
- Generator
- Einstellungen

Nur das Reimarchiv wird aktuell aktiv entwickelt. Die anderen Bereiche dürfen als einfache, eindeutig gekennzeichnete Navigationsziele bestehen bleiben. Keine künstlich ausgearbeiteten Unterseiten.

### Grundregel

Jedes sichtbare Element muss mindestens einen konkreten Zweck erfüllen.

Keine UI-Elemente nur deshalb erstellen, weil sie für zukünftige Funktionen vorgesehen sind.

Keine doppelten Informationen, keine dekorativen Statistiken, keine unnötigen Karten.

### Arbeitsprinzip

Die Anwendung soll sich wie ein Werkzeug anfühlen, nicht wie ein Dashboard zur Verwaltung eines Entwicklungsprojekts.

Fokus auf dem tatsächlichen Arbeitsbereich: Reimwörter suchen, kategorisieren, anzeigen und hinzufügen.

Bestehende technische Funktionalität erhalten. Keine unnötigen Architekturänderungen.

Ziel: maximale funktionale Dichte bei minimaler Oberfläche.
